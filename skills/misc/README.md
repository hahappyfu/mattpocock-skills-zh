# Misc

备而少用的工具，不在插件中推广。

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)**：设置 Claude Code 的 hook，在危险的 git 命令 (push、reset --hard、clean 等) 执行前拦截。
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)**：把测试文件中的 `as` 类型断言换成 @total-typescript/shoehorn。
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)**：创建带章节、题目、参考实现和讲解材料的练习目录结构。
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)**：设置 Husky pre-commit hook，含 lint-staged、Prettier、类型检查和测试。
